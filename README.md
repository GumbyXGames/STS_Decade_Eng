<h1>Kamen Rider Decade Retranslation (dcd_eng)</h1>
A Mod of <a href="https://steamcommunity.com/sharedfiles/filedetails/?id=1970442101">Kamen Rider Decade Mod by 红色有角三倍速 and 树</a> that edits the English translation of added cards so they are easier to read and understand. Game keywords and terminology has been updated to be inline with other English mods.<br>

<h3>Requirements</h3>
Mod requires BaseMod
<ul>
  <li><a href="https://steamcommunity.com/workshop/filedetails/?id=1605833019">BaseMod from the Steam Workshop</a></li>
  <li><a href="https://github.com/daviscook477/BaseMod">BaseMod on GitHub</a></li>
</ul>
<h3>Use</h3>
Copy jar file to the mod directory/folder in the SlayTheSpire game directory/folder:
<ul>
  <li><b>Windows</b>: C:\Program Files (x86)\Steam\steamapps\common\SlayTheSpire\mods\
  <li><b>Linux</b>: /home/&lt;<i>user_directory</i>&gt;/.local/share/Steam/steamapps/SlayTheSpire/mods/
  <li><b>MacOS</b>: /Users/&lt;<i>user_directory</i>&gt;/Library/Application Support/Steam/steamapps/common/SlayTheSpire/SlayTheSpire.app/Contents/Resources/mods/
</ul>
If the directory/folder does not exist, you can create it.<br>
<br>
For those who would like to build the jar themselves, I have added Maven profiles for MacOS, Linux, and Windows.
